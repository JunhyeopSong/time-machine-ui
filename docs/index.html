time-machine-ui

Shared design for the time-machine products: Continental Time Machine and the upcoming Human Journey.

Load in this order, then the product's own styles:

<link rel="stylesheet" href="https://junhyeopsong.github.io/time-machine-ui/v1/tokens.css">
<link rel="stylesheet" href="https://junhyeopsong.github.io/time-machine-ui/v1/base.css">
<script src="https://junhyeopsong.github.io/time-machine-ui/v1/ui.js"></script>

  • v1/ gets compatible fixes; breaking changes go to v2/.
  • v1.0.0/, v1.1.0/ … are exact versions that never change.
  • v1/products.json lists the products for the product switcher.
